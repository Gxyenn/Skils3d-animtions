# Agent instructions

This repository is the `cartoon-3d-short` skill: vertical cartoon story shorts (three.js + Remotion).

- When the user asks for a cartoon or animated 3D story short, or a video "like the bridge short", read `AI_INSTRUCTIONS.md` first, then `SKILL.md`, and follow them step by step.
- Wait for the user to approve the script before building anything.
- If you cannot run commands or edit files, you cannot render: do the planning steps only, then hand off. Never claim you rendered something you did not.
- Story, characters and voice are always the user's own. Never copy another channel's scripts, characters or shots.
- Reference frames and contact sheets (`references/frames/`, `references/sheets/`) come from other people's videos and are for style study only: never reuse their characters, shots or scripts.
- More: `docs/USING_WITH_AI.md`.
